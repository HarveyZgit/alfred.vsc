## 背景

VSC Alfred workflow 用于快速访问 VSCode 项目。管理面板功能（`vscli manage`）虽然已部分实现，但存在多个阻止其正常工作的 bug：

1. `shared.py` 缺少 `get_git_branch_for_browse` 和 `update_branches_cache` 函数
2. `server.py` 的 `WEB_DIR` 路径错误（指向 `src/` 而不是 `src/web/`）
3. `dev_install.py` 没有符号链接 `server.py` 或 `web/` 目录
4. Alfred List Filter 项目中没有包含正确的 `manage start/stop` 命令

目标实现（按 wanted.md）是本地 Web 管理面板，包含 5 个标签页：总览、项目、回收站、目录、设置。

**重要**：管理面板只管理 cache.json，不直接访问任何数据库。

## 命令设计

| 命令 | 行为 |
|------|------|
| `vscli manage start` | 启动服务器在 3847 端口，自动打开浏览器；如果已启动则只打开浏览器 |
| `vscli manage stop` | 停止服务器 |

**注意**：Alfred List Filter 提供两个独立选项 "🚀 启动管理面板" 和 "⏹ 停止管理面板"，用户选择后通过 `manage start` 或 `manage stop` 参数传递给脚本。

## 目标 / 非目标

**目标：**
- 修复所有阻止管理面板正常工作的 bug
- 实现 cache.json 的增删改查操作
- 确保 `manage start/stop` 命令可以从 Alfred 关键字正常工作
- 正确提供 SPA 服务，包含所有静态资源（HTML、JS、CSS）

**非目标：**
- 直接读取 VSCode DB 或 storage.json
- 用户认证或多用户支持
- 实时更新（轮询即可，30秒间隔可接受）
- 移动端响应式设计（桌面优先）

## 技术决策

### 决策 1：HTTP 服务器实现
**选择**：Python 标准库 `http.server.HTTPServer` + 自定义 `SimpleHTTPRequestHandler`

**理由**：按 wanted.md 要求"零依赖：纯 Python stdlib http.server，无需安装任何包"

### 决策 2：SPA 架构
**选择**：原生 JS SPA（无框架）

**理由**：符合现有项目风格（仅 Python），保持包体积小，无需构建步骤

### 决策 3：数据存储
**选择**：通过 `server.py` 直接读写 cache.json 文件

**理由**：与 Alfred workflow 共享同一个 JSON 文件；原子写入防止数据损坏

### 决策 4：API 响应格式
**选择**：`{ok: bool, data: ..., error?: string}` 信封模式

**理由**：一致的错误处理，前端容易判断成功/失败

### 决策 5：端口选择
**选择**：默认 3847，如果被占用则自动往后顺延

**理由**：避免需要特权端口

## 风险 / 权衡

| 风险 | 缓解措施 |
|------|----------|
| Alfred 和管理面板同时访问 | 通过操作系统文件锁保证不会同时写入 |
| 服务器崩溃导致孤儿进程 | PID 文件 + `manage stop` 命令 |
| 记录数量多导致性能慢 | API 分页，UI 虚拟化列表 |

## 交互设计

### 组件状态

| 组件 | 状态 |
|------|------|
| 项目卡片 | 默认、hover（边框高亮）、选中（蓝色边框） |
| 按钮 | 默认、hover、active、disabled |
| 输入框 | 默认、focus（蓝色边框）、error（红色边框） |
| 标签 | 默认、hover、active（左侧蓝色指示条） |
| Toast | 成功（绿）、错误（红）、警告（黄），3秒自动消失 |

### 交互行为

| 操作 | 行为 |
|------|------|
| 点击侧边栏标签 | 切换主内容区，无页面刷新 |
| 点击项目卡片的删除 | 移动到回收站，显示 toast，确认 |
| 点击回收站的恢复 | 恢复到项目列表，显示 toast |
| 点击回收站的永久删除 | 弹出确认对话框，确认后永久删除 |
| 拖拽项目卡片 | 可拖拽排序，拖拽时显示占位符 |
| 输入搜索 | 300ms 防抖，实时过滤显示 |
| 点击顶部"打开" | 用 VS Code 打开选中项目 |
| 点击顶部"Rebuild" | 调用 API 重建索引，显示 loading |

### 空状态

| 页面 | 空状态文案 |
|------|-----------|
| 项目页 | 🗂️ 暂无项目，请先用 Alfred 打开一些项目 |
| 回收站 | ✅ 回收站是空的 |
| 目录页 | 📁 未配置目录，请在设置中添加 |

### 加载状态

- 页面切换时：显示 spinner
- API 请求中：按钮显示 loading 状态
- 数据加载中：显示骨架屏或占位符

### 错误处理

| 错误 | 处理方式 |
|------|----------|
| API 请求失败 | 显示红色 toast，3秒消失 |
| 服务器连接断开 | 每 30s 轮询检测，断开时显示重连按钮 |
| 操作失败（如删除失败） | 显示具体错误信息的 toast |

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `1-5` | 切换侧边栏标签 |
| `/` 或 `Cmd+K` | 聚焦搜索框 |
| `Esc` | 清除搜索 / 关闭对话框 |
| `Delete` | 删除选中项目（需确认） |
